# OROMIA FOREST RESOURCE MONITORING SYSTEM (OFRMS)

## User Manual

### Oromia Environmental Protection Authority (OEPA)

**Oromia Forest Resource Monitoring System (OFRMS)**

---

# 1. Introduction

The **Oromia Forest Resource Monitoring System (OFRMS)** is a web-based geospatial information and forest-resource monitoring platform developed to support the collection, management, visualization, analysis, and dissemination of forest and natural-resource information across Oromia Regional State, Ethiopia.

The system provides a centralized platform through which authorized users can access spatial datasets, view forest-resource maps, explore geographic information, review metadata, and download datasets for further analysis and reporting.

OFRMS uses modern geospatial technologies and web-based mapping infrastructure to make forest-resource information more accessible to decision-makers, technical experts, researchers, planners, development partners, and other authorized stakeholders.

The platform supports evidence-based forest management by bringing together geographic datasets and forest-related information in a common environment.

---

# 2. Purpose of the OFRMS

The main purpose of OFRMS is to provide a reliable and accessible platform for managing and monitoring forest resources and related environmental information in Oromia.

The system is intended to:

- Support forest-resource monitoring and assessment.
- Provide centralized access to spatial datasets.
- Visualize forest-cover and forest-resource information on interactive maps.
- Support comparison and interpretation of spatial datasets.
- Provide information for forest planning and management.
- Support environmental and natural-resource decision-making.
- Improve access to geospatial information among authorized institutions.
- Support reporting, research, and technical analysis.
- Provide downloadable spatial data for further GIS analysis.
- Strengthen institutional management of forest-related geospatial information.

---

# 3. OFRMS Platform

OFRMS is implemented as a web-based geospatial information platform using **GeoNode** and related open-source geospatial technologies.

The platform allows users to work with different types of geospatial resources, including:

- Vector datasets
- Raster datasets
- Forest-cover datasets
- Administrative boundaries
- Monitoring datasets
- Reference layers
- Maps
- Documents and supporting resources

The system provides an interactive map interface through which users can overlay and examine different geographic datasets.

---

# 4. Accessing OFRMS

Open a web browser such as Google Chrome, Microsoft Edge, or Mozilla Firefox.

Navigate to the OFRMS web portal:

**https://ofrms.edu.et**

The OFRMS home page provides access to the major resources available on the platform.

The interface normally provides access to:

- Home
- Layers
- Maps
- Documents
- Search
- About
- User account
- Map visualization tools

> **Note:** Some functions may only be available to authenticated users depending on the user's assigned permissions.

---

# 5. OFRMS Home Page

The OFRMS home page provides an overview of the platform and provides links to available geospatial resources.

From the home page, users can search for datasets, open maps, access available documents, and navigate to the map viewer.

The home page can be used as the starting point for accessing forest-resource information.

---

# 6. Searching for Forest Datasets

To find a dataset:

1. Open the OFRMS portal.
2. Navigate to **Layers**.
3. Use the search box.
4. Enter the name or keyword of the required dataset.
5. Review the search results.
6. Select the required dataset.

For example, users can search for:

- Forest
- Forest coverage
- Forest cover
- Land cover
- Administrative boundary
- Oromia
- Zone
- Woreda
- Monitoring

The search results provide information about available datasets and allow the user to open the selected resource.

---

# 7. Forest Coverage Dataset

One of the important datasets available through OFRMS is the **Forest Coverage** dataset.

The dataset provides spatial information about forest coverage and can be visualized through the OFRMS map interface.

For example:

**Dataset:** Forest Coverage  
**Year:** 2024  
**Owner:** Shife  
**Area:** Oromia  
**Unit:** hectare (ha)

The dataset can be opened from the **Layers** section and displayed on the interactive map.

---

# 8. Opening a Dataset

To open a dataset:

1. Select **Layers**.
2. Search for the required dataset.
3. Click the dataset name.
4. Review the dataset information page.
5. Select **View** or **Open Map**.
6. The dataset will be displayed in the map viewer.

The dataset information page may provide:

- Dataset title
- Description
- Owner
- Date
- Keywords
- Geographic extent
- Coordinate reference system
- Data type
- Metadata
- Download options
- Map visualization options

---

# 9. Exploring the Interactive Map

The OFRMS map viewer allows users to explore geographic information interactively.

Users can:

- Zoom in
- Zoom out
- Pan the map
- Identify geographic features
- Turn layers on and off
- Change the map background
- View attribute information
- Measure distances
- Measure areas
- Search for geographic locations

The map provides an interactive environment for examining the spatial distribution of forest resources.

---

# 10. Navigating the Map

### Zoom In

Use the **+** button to zoom into the map.

### Zoom Out

Use the **−** button to zoom out.

### Pan

Click and drag the map to move to another location.

### Full Extent

Use the map extent control to return to the full geographic extent of the selected dataset.

### Feature Information

Use the identify or information tool to select a feature and view its available attribute information.

---

# 11. Layer Management

The map viewer allows users to manage multiple geographic layers.

A user can:

- Add layers.
- Remove layers.
- Turn layers on or off.
- Change layer order.
- Adjust layer transparency.
- Compare different datasets.

For example, a forest-cover layer can be displayed together with:

- Oromia regional boundary
- Zone boundaries
- Woreda boundaries
- Roads
- Rivers
- Other environmental datasets

This makes it possible to understand the geographic relationship between forest resources and other landscape features.

---

# 12. Viewing Forest Coverage

To visualize forest coverage:

1. Open the **Forest Coverage** dataset.
2. Select **View**.
3. Open the map viewer.
4. Zoom to the area of interest.
5. Examine the displayed forest coverage.
6. Use the identify tool to inspect individual features where attribute information is available.

The forest coverage map provides a spatial representation of forest resources within the selected geographic area.

---

# 13. Administrative Boundary Analysis

Administrative boundary datasets can be used to understand forest resources according to administrative units.

Users can overlay forest datasets with:

- Regional boundaries
- Zones
- Woredas
- Kebeles

This allows technical users to identify the distribution of forest resources within specific administrative areas.

For example, a user can overlay the forest coverage dataset with woreda boundaries to identify the forest resources occurring within individual woredas.

---

# 14. Viewing Dataset Information and Metadata

Metadata provides important information about a dataset.

Before using a dataset, users should review its metadata.

Important metadata may include:

- Dataset name
- Description
- Data owner
- Data source
- Year
- Spatial reference system
- Geographic extent
- Data format
- Resolution
- Update information
- Keywords
- License
- Data quality information

Metadata helps users understand how the dataset was produced and how it should be used.

---

# 15. Downloading Data

Where download permission has been enabled, users can download datasets for further analysis.

To download a dataset:

1. Open the required layer.
2. Select the **Download** option.
3. Select the required format.
4. Download the dataset.
5. Open the downloaded data using GIS software such as QGIS or ArcGIS.

Depending on the dataset and permissions, available formats may include:

- GeoPackage
- Shapefile
- GeoJSON
- CSV
- KML/KMZ
- Raster formats

> Download availability depends on the dataset owner and the permissions assigned to the user.

---

# 16. Working with OFRMS Maps

OFRMS allows users to create and view web maps by combining multiple spatial datasets.

A map can contain several layers representing different aspects of the landscape.

For example:

**Base Map**

+ **Oromia Boundary**

+ **Zone Boundaries**

+ **Woreda Boundaries**

+ **Forest Coverage**

+ **Other Forest Resource Layers**

This provides a comprehensive geographic view of forest resources.

---

# 17. Creating a Map

Authorized users can create maps by combining available layers.

General workflow:

1. Open **Maps**.
2. Select **Create Map**.
3. Add the required layers.
4. Arrange the layer order.
5. Adjust layer visibility.
6. Configure layer styles.
7. Configure the map extent.
8. Save the map.
9. Provide a suitable map title and description.

A map should have a clear title and description so that other users can understand its purpose.

---

# 18. Layer Styling

Layer styling controls how geographic features appear on the map.

For example, forest areas can be displayed using an appropriate forest-related visualization.

Users with appropriate permissions can configure:

- Fill color
- Outline
- Transparency
- Labels
- Classification
- Symbols

Styling should be designed to make the map easy to interpret.

---

# 19. Comparing Spatial Information

OFRMS can be used to compare different spatial datasets.

For example, users may compare:

- Forest coverage
- Land-use/land-cover
- Administrative boundaries
- Protected areas
- Other environmental datasets

By turning layers on and off or changing transparency, users can identify spatial relationships and differences.

# 20. Forest Resource Monitoring

OFRMS supports forest-resource monitoring by providing a centralized environment for accessing spatial information.

Monitoring activities can include:

- Forest-cover assessment
- Forest-resource mapping
- Spatial comparison
- Identification of forest areas
- Monitoring changes in forest distribution
- Administrative-level analysis
- Preparation of maps and reports

The system can be progressively expanded as additional forest-monitoring datasets become available.

---

# 21. Data Update and Management

OFRMS datasets should be updated according to the responsible institution's data-management procedures.

When a new dataset becomes available, authorized administrators can:

1. Prepare the dataset.
2. Verify the data.
3. Prepare metadata.
4. Upload the dataset.
5. Configure its visualization.
6. Assign appropriate permissions.
7. Publish the dataset.
8. Verify the published layer.

Data should be checked before publication to ensure that it is complete, correctly projected, appropriately documented, and suitable for its intended purpose.

# 23. Data Quality

Users should consider data quality before using OFRMS information for planning or decision-making.

Important considerations include:

- Data source
- Data collection date
- Spatial resolution
- Positional accuracy
- Classification accuracy
- Completeness
- Projection
- Update frequency
- Processing methodology

The most recent available dataset should be used where current information is required.
